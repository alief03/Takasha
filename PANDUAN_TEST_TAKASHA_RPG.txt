RINGKASAN PENYEMPURNAAN SHOWCASE (v1.8.7 / v2.8.7):
----------------------------------------------------------------------------------------
1. Animasi Tekstur Lidah Api Blazestaff (Flickering Flame Animation):
   - Root Cause: File `flame_debuff.png.mcmeta` sebelumnya mengandung tag malformed `"mcmodels": ""`
     yang merusak generator ticker atlas Minecraft 26.2, membekukan animasi api senjata.
   - Perbaikan: 12 file `.mcmeta` dibersihkan dan distandarkan menjadi `{"animation":{"frametime":2,"interpolate":true}}`,
     menghasilkan animasi nyala lidah api 10 frame yang berkobar dinamis dan halus di ujung tongkat Blazestaff.

2. Animasi Casting & Ayunan Lengan Pemain (Player Arm Swing Animations):
   - `MMOInteractionHandler` kini memanggil `player.swing(hand, true)` pada seluruh interaksi:
     * Klik Kanan (RMB - Volcanic Spear)
     * Shift + Klik Kanan (Shift+RMB - Magma Dash)
     * Double-Tap Sneak (Shift + Shift - Hellfire Overblast)
     * Hold Sneak >= 0.5s (Hold Shift - Firestorm Volley)
     * Air-Swings (Klik Kiri udara kosong - Pyro Combo & Infernal Judgement)
   - Karakter pemain tidak lagi kaku seperti patung saat merapal mantra dan jurus!

3. 3D Model Flipbook Sequencer (Volcanic Spear, Explosion, & Earthquake Rupture):
   - `ActiveModelInstance` kini dilengkapi sekuenser model frame multi-step:
     * Volcanic Spear: Transisi frame 1..8 secara dinamis (`volcanic_spear_1` -> `volcanic_spear_8`)
       menciptakan tebasan tombak magma yang memanjang dan melesat seperti video showcase!
     * VFX Explosion: Rangkaian frame ledakan api 1..12 (`vfx_explosion_1` -> `vfx_explosion_12`).
     * VFX Earthquake Rupture: Transisi retakan tanah 1..5 (`vfx_earthquake_rupture_1` -> `5`) dengan delay tanah retak 44-tick.

4. Routing Gesture Langsung (Direct Cast Routing):
   - Double-Tap Sneak kini merutekan langsung ke `Hellfire_Overblast_CAST` (melewati deadlock aura timer Bukkit).
   - Hold-Sneak (>=10 tick) kini merutekan langsung ke `Firestorm_Volley_CAST`.

5. Sinkronisasi Siklus Hidup Heat Mastery & Sound Pitch Progression:
   - `ActiveOrbital` kini mendeteksi jumlah stack aura `HEAT` secara real-time:
     * Stack 1: Model `stack_black1`, sound `block.trial_spawner.spawn_item` pitch 0.75.
     * Stack 2: Model `stack_black2`, sound `block.trial_spawner.spawn_item` pitch 1.00.
     * Stack 3: Model `stack_black3`, sound `block.trial_spawner.spawn_item` pitch 1.25 + partikel lava.
     * Konsumsi Ignition: Begitu skill membakar stack `HEAT` menjadi 0, model orbital langsung dihapus secara instan!

6. Akselerasi Ballistics & Midair Hover Suspension:
   - `ModifyProjectileMechanic` kini mengeksekusi `action=MULTIPLY` (`speed * val`), mengakselerasi rudal abu dan bola api secara bertahap di udara.
   - `LungeMechanic` pada Infernal Judgement kini mengontrol gravitasi secara akurat saat `velocity <= 0.05`, menahan pemain melayang di udara selama 65 tick sambil memanggil tombak sebelum menukik membanting tanah.
   - `@EntitiesInCone` fallback: Jika tidak ada musuh di depan pemain, serangan tetap melesat lurus ke arah crosshair (15 blok) tanpa macet di kaki.
   - `ActiveProjectile.java` kini dilengkapi raycasting voxel tanah (`level.clip(...)`).
   - Meteor tidak lagi melayang statis di langit! Meteor menukik diagonal ke tanah, meledak hebat pada kontak
     permukaan (`onHit`), serta memunculkan batuan retak, letusan magma (`VFX_LAVA_RUPTURE`), dan kawah api.

4. Perbaikan Penjadwalan Repeat & Delay Skill (Authentic Float & Multi-Beam):
   - `MythicSkillExecutor` kini memproses `repeatCount` dan `repeatInterval` secara akurat bersamaan dengan `delay`.
   - Infernal Judgement: Pemain melayang stabil di udara selama 65 tick sambil memanggil lingkaran sihir neraka
     dan menghujani tombak magma sebelum menukik membanting ke tanah.
   - Hellfire Overblast: Menembakkan semburan laser api berkelanjutan (15 gelombang beam bertubi-tubi) selama 4 detik.
   - Magma Dash: Meluncur ke depan meninggalkan jejak lava berurutan yang meledak bertahap.

4. Implementasi Penuh 7 Skill Samus Awakened Pyromancer (100% Sesuai Showcase):
   - Passive: Heat Mastery (LMB -> 1 Heat stack, 3 stacks -> Mode Ignition dengan api crimson tua).
   - Basic Attack (LMB): Pyro Combo 4-Strike sequence:
     * Serangan 1 & 2: Ash Missile melesat lurus ke depan.
     * Serangan 3: Flame Shockwave berbentuk kipas (cone).
     * Serangan 4: Meteor raksasa jatuh diagonal dari langit lalu meledak menghantam tanah.
   - Skill 1 (RMB): Volcanic Spear Combo (Jab -> Flaming Slash -> Upward Slash -> Slam -> Piercing Jab).
     * Mode Ignition: Tombak memanjang dan berwarna merah tua pekat.
   - Skill 2 (Shift + Shift / Double-Tap Sneak): Hellfire Overblast (Semburan beam api continue 4 detik).
     * Mode Ignition: Beam merah crimson dengan daya dorong knockback bertahap.
   - Skill 3 (Hold Shift >= 0.5s): Firestorm Volley (Bola api berputar spiral membentuk bola lalu jatuh menghujani musuh terdekat).
     * Mode Ignition: Ledakan area (AoE) besar pada tiap benturan.
   - Skill 4 (Shift + RMB): Magma Dash (Melesat cepat meninggalkan jejak lava cair yang membakar).
     * Mode Ignition: Jejak lava retak dan meledak beruntun (sequential rupture explosions).
   - Ultimate Skill (Shift + LMB): Infernal Judgement (Melompat ke udara, lingkaran sihir bercahaya muncul di kiri-kanan, menembakkan hujan tombak api ke target arah pandangan).

5. Perbaikan Bug Reset Mana (State Clamping Persistence):

6. Restriksi Mode Kreatif pada Perintah MMO Samus:
